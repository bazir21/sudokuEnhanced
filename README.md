# Sudoku.com Enhanced Browser Extension

This is a browser extension for Firefox to enhance the functionality of [Sudoku.com](https:www.sudoku.com).

The main additions of this extension is adding support for dark mode, rebindable keyboard shortcuts, and clutter removal for every page on the Sudoku.com domain. This extension also features local storage for these settings to be maintained.
